# mlog-plataforma-b2b

Site em Next.js para MundoLogística (Plataforma Educacional & B2B).

## Desenvolvimento Local (Docker)

```bash
make up
```

Ou diretamente com Next.js (`Node >= 20.9.0`):

```bash
npm install
npm run dev
```

## Build & Deploy

- **Servidor Node.js (Hostinger / Next.js):** `npm run build` e `npm run start`
- **Exportação Estática (`out/`):** `npm run build:export`
